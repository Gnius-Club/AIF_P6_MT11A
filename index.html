🎯 Objetivo de Aprendizaje

Los estudiantes podrán: Comprender la IA distribuida y la colaboración multiagente. Usar el Micro:Bit y el XGO para enviar y recibir mensajes por radio y sincronizar acciones entre robots.

🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Quiero aprender cómo dos robots pueden colaborar como un equipo usando comunicación por radio en Python. Explícame primero qué significa un sistema multiagente y por qué la coordinación es más difícil cuando hay más de un robot. Luego enséñame cómo usar xgo.radio_send(msg) y xgo.radio_receive() para que un robot envíe una señal y el otro responda. Guíame a construir un flujo simple: Robot A detecta algo (o simula detección), envía mensaje, Robot B recibe y avanza con xgo.move_forward(speed). Incluye cómo manejar errores comunes: mensajes perdidos, retraso, duplicación, y cómo crear una confirmación (“ack”) para asegurar que la comunicación ocurrió.

🚨 Resolución Rápida de Problemas

  • Si los alumnos no pueden ingresar a Gnius Space: Activa XOLO SOS en xolo.gnius.club para continuar la misión sin interrumpir la clase.
  • Si los robots no se comunican: Asegúrate de que ambos Micro:bit estén en el mismo 'Grupo de Radio' en MakeCode.
  • Si el XGO no se mueve: Verifica que el Micro:bit esté bien insertado y que la batería del robot tenga carga suficiente.
  • Si falla la Smart A.I. Lens: Verifica que el lente esté limpio, que el cable esté bien conectado y que haya buena iluminación para reconocer las tarjetas.
  • Si hay errores en el código: Recordar a los estudiantes que XOLO puede ayudar a depurar. Pídeles que copien el error y se lo muestren a XOLO.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a idear una misión colaborativa en Python donde dos XGO trabajen como “Vigilante” y “Transportador”. Quiero que el Vigilante explore y cuando encuentre una señal (tarjeta o evento), envíe un mensaje al Transportador para que venga a “rescatar” o recoger algo. Después genera el código en Python para ejecutarlo, de acuerdo a tu entrenamiento con el robot XGO y Micro:bit, con dos programas separados (uno para cada robot), reglas claras de comunicación y una forma de probar fallas (ej: ¿qué pasa si el mensaje no llega?)."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿El robot Transportador reacciona inmediatamente cuando el Vigilante envía la señal?
  • ¿Qué pasa si pones un obstáculo físico grande entre los dos robots mientras intentan comunicarse?
  • ¿Funciona igual la comunicación si los robots están a 1 metro de distancia vs 5 metros?
  • Si los robots no se ponen de acuerdo en quién debe moverse primero, ¿cómo afecta esto a la seguridad de la misión?
  • ¿Por qué es necesario que el robot que recibe el mensaje envíe una confirmación de vuelta para evitar conflictos?

¡Es hora de crear nuestra propia misión de rescate! Vamos a usar a XOLO para idear un proyecto donde un XGO sea el 'Vigilante' y otro el 'Transportador'. Imaginen que el Vigilante encuentra un objeto peligroso y debe llamar al Transportador para que lo recoja. Primero, pidan a XOLO que les ayude con la idea y el VIBE, luego sigan su GCS para programar en MakeCode. Prueben primero en el simulador y, cuando estén listos, les entregaré los XGO. No olviden revisar las preguntas de experimentación para ver qué pasa si la radio falla. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar.
